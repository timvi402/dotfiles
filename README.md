# Dotfiles

My personal configuration files managed with GNU Stow.

## Structure

Each directory represents a package that can be stowed independently:
- `bash/` - Bash configuration
- `zsh/` - Zsh configuration
- `git/` - Git configuration
- `nvim/` - Neovim configuration
- `kitty/` - Kitty terminal configuration
- `matugen/` - Matugen config + templates (Chromium theme colour from wallpaper)
- `omarchy/` - Overrides for omarchy commands, shadowed via `~/.local/bin`

### Zsh layout

`.zshrc` holds environment, options and plugin loading, then sources the rest.
Load order matters — each file below depends on the ones above it:

| File | Contents |
| --- | --- |
| `.zshrc` | Environment, shell options, Oh My Zsh, sourcing order |
| `.zsh_profile` | Editor vars, autocomplete keybindings |
| `.zsh_alias` | Aliases |
| `.zsh_fzf_theme` | fzf colors + `_fzf_footer` / `FZF_PREVIEW_*` helpers |
| `.zsh_pw_search` | Password-manager fuzzy search (Ctrl+B) |
| `.zsh_widgets` | fzf pickers, directory navigation, Iris integration |
| `.p10k.zsh` | Generated by `p10k configure` — do not hand-edit |
| `.p10k-colors.zsh` | Contrast fixes, kept out of `.p10k.zsh` so regenerating it is safe |

## Usage

### Install all dotfiles
```bash
cd ~/dotfiles
stow */
```

### Install specific package
```bash
cd ~/dotfiles
stow zsh
```

### Uninstall package
```bash
cd ~/dotfiles
stow -D zsh
```

### Re-stow (useful after adding new files)
```bash
cd ~/dotfiles
stow -R zsh
```

## Setup on a new machine

```bash
git clone https://github.com/timvi402/dotfiles ~/dotfiles
cd ~/dotfiles
stow */
```

## Adding new dotfiles

1. Create package directory if needed: `mkdir -p ~/dotfiles/package_name`
2. Move the dotfile: `mv ~/.config/app ~/dotfiles/package_name/.config/`
3. Stow the package: `cd ~/dotfiles && stow package_name`
4. Commit: `git add . && git commit -m "Add app config"`
